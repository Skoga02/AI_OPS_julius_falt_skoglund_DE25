Hej Annika! Kul att du vill jobba med tågspår.
1. Sök YH-utbildning inom järnväg/anläggning (t.ex. via yhguiden.se) eller relevant gymnasieprogram; Trafikverket och entreprenörer erbjuder också säkerhets- och spårkurser.
2. Skaffa gärna B-körkort och sök tjänster som spårarbetare eller anläggningsarbetare hos Trafikverket och järnvägsentreprenörer.
3. Med erfarenhet kan du utvecklas till arbetsledare, spårinriktare eller projektledare.
