Hej Annika! Här är ett enkelt sätt att börja:

- Kika på Yrkeshögskolan (YH) efter utbildningar inom järnvägsteknik eller spårarbete, eller fråga Arbetsförmedlingen om yrkesvägledning.
- Skaffa säkerhetsutbildning för spårmiljö (t.ex. TSJ) och körkort B, sedan ansök om spårarbete hos Trafikverket, Infranord, Strukton eller Colas Rail.
- Räkna med fysiskt arbete utomhus i alla väder och skift; svetsning och maskinkörning kan du lära dig via YH eller på arbetsplatsen.

Lycka till, Annika – det låter som ett spår som passar dig!
